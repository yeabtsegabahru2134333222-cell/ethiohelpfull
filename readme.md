# Ethiohelpful — v2

A free, honest guidance platform for Ethiopian high-school students.

## What’s included

- Clean dashboard
- Smarter local AI guide (uses your profile, varies replies)
- Personal roadmap + milestones
- Path ideas (Engineering, Medicine, CS, Business, Study Abroad, etc.)
- Student profile
- Exploration journal
- Everything saved in browser localStorage
- Responsive design
- Clear AI-mistake disclaimer

## Important

This is a **front-end prototype**. The AI guide uses local rules so you can test without a server or API key.

To connect a real AI later (Grok, Claude, GPT), use a secure backend or serverless function. Never put a private API key in the browser.

Open `index.html` in a browser to use it.
